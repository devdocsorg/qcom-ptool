# Layout loaders

Readers that turn a layout file into the form in [spec.py](../spec.py).

## Files

- [`__init__.py`](__init__.py) — Chooses the loader from the file suffix.
- [conf.py](conf.py) — Reads the `--disk` and `--partition` line format.
- [README.md](README.md) — Describes this folder and indexes its contents.
- [yaml.py](yaml.py) — Reads and validates single-storage YAML layouts.
