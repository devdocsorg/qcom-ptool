# degpt source

The degpt program and its GPT parsing library.

## Folders

- [mygpt/](mygpt/README.md) — Holds the GPT header and partition entry parsers.

## Files

- [lib.rs](lib.rs) — Exposes the `mygpt` module as a library.
- [main.rs](main.rs) — Implements the command line and writes the XML.
- [mygpt.rs](mygpt.rs) — Declares the parser modules and re-exports their types.
- [README.md](README.md) — Describes this folder and indexes its contents.
