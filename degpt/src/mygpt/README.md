# GPT parsing

The `mygpt` module: little-endian parsers and printable forms for GPT structures.

## Files

- [README.md](README.md) — Describes this folder and indexes its contents.
- [header.rs](header.rs) — Defines the GPT header and parses it from on-disk bytes.
- [partition.rs](partition.rs) — Defines a GPT partition entry and parses it from on-disk bytes.
