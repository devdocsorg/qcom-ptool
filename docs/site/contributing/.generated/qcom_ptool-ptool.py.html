qcom_ptool.ptool.UpdatePatch(StartSector, ByteOffset, PHYPartition, size_in_bytes, szvalue, szfilename, szwhat)¶

Append a patch element to the global PatchesXML tree.

Parameters:

  • StartSector (str) -- Sector to patch, as text such as "NUM_DISK_SECTORS-1.".

  • ByteOffset (str) -- Byte offset within the sector, as text.

  • PHYPartition (int) -- Physical partition (LUN) number.

  • size_in_bytes (int) -- Number of bytes the patch writes.

  • szvalue (str) -- Value expression evaluated by the flashing tool.

  • szfilename (str) -- File to patch, or DISK for the device itself.

  • szwhat (str) -- Human-readable description of the patch.

Example: UpdatePatch("1", "32", 0, 8, "NUM_DISK_SECTORS-1.", "DISK", "Update last LBA")

qcom_ptool.ptool.UpdateRawProgram(RawProgramXML, StartSector, size_in_KB, PHYPartition, file_sector_offset, num_partition_sectors, filename, sparse, label, readbackverify='false', partofsingleimage='false')¶

Append a program element, and optionally an erase element, to a rawprogram tree.

A negative StartSector is written relative to NUM_DISK_SECTORS. With the -e option, every partition except cdt is erased before it is programmed.

Parameters:

  • RawProgramXML (xml.etree.ElementTree.Element) -- Rawprogram tree that receives the elements.

  • StartSector (int) -- First sector; negative values count back from the end of the disk.

  • size_in_KB (int | float) -- Partition size in kilobytes.

  • PHYPartition (int) -- Physical partition (LUN) number.

  • file_sector_offset (int) -- Sector offset within the source file.

  • num_partition_sectors (int) -- Partition size in sectors; values below 1 become 0.

  • filename (str) -- Image written to the partition, or an empty string.

  • sparse (str) -- "true" when the image is a sparse image.

  • label (str) -- Partition label.

  • readbackverify (str) -- "true" to request read-back verification.

  • partofsingleimage (str) -- "true" when the image is part of a single disk image.

Example: UpdateRawProgram(RawProgramXML, 0, 0.5, 0, 0, 1, "gpt_main0.bin", "false", "PrimaryGPT")

Write the zero files and the wipe_rawprogram_PHY<N>.xml files.

qcom_ptool.ptool.CreateGPTPartitionTable(PhysicalPartitionNumber, UserProvided=False)¶

Build the GPT, rawprogram and patch files for one physical partition.

Partitions from the parsed XML are placed in order, aligned to the write-protect boundary where requested, and written to gpt_main<N>.bin, gpt_backup<N>.bin, gpt_both<N>.bin, gpt_empty<N>.bin, rawprogram<N>.xml, patch<N>.xml, and the rawprogram<N>_BLANK_GPT.xml and rawprogram<N>_WIPE_PARTITIONS.xml variants.

Parameters:

  • PhysicalPartitionNumber (int) -- Physical partition (LUN) number N.

  • UserProvided (bool) -- True when N came from -p; a missing partition then exits.

Raises:

SystemExit -- When a user-selected partition is missing or the layout is invalid.

Example: CreateGPTPartitionTable(0) writes gpt_main0.bin and rawprogram0.xml.

qcom_ptool.ptool.ValidatePartitions()¶

Validate the partition layout:

  • duplicate --name entries are checked per-LUN (two partitions sharing a name on one LUN cannot be addressed unambiguously);

  • A/B slot pairing is checked across all LUNs, since some boot firmware (e.g. xbl_a on LUN1, xbl_b on LUN2) is split across separate boot LUNs by design.

Raises:

SystemExit -- With status 1 when a duplicate name or unpaired slot is found.

Example: ValidatePartitions() exits when LUN 0 has two efi partitions.
