qcom_ptool.gen_contents.usage()¶

Print the gen_contents usage text and exit.

Raises:

SystemExit -- Always, with status 1.

Example: qcom-ptool gen_contents -h calls this function.

qcom_ptool.gen_contents.ParseXML(XMLFile)¶

Parse an XML file and return its root element.

Parameters:

XMLFile (str) -- Path of the XML file to parse.

Returns:

The root element, or None after printing an error when the file is missing or malformed.

Return type:

xml.etree.ElementTree.Element | None

Example: ParseXML("partitions.xml").tag returns "configuration".

qcom_ptool.gen_contents.UpdateMetaData(TemplateRoot, PartitionRoot, BuildId)¶

Fill a contents template with build IDs and the files a partition XML needs.

Every builds_flat/build receives a build_id. In the common build, the placeholder download_file, partition_file and partition_patch_file entries are replaced with one entry per partition image, GPT file, rawprogram file and patch file.

Parameters:

  • TemplateRoot (xml.etree.ElementTree.Element) -- Root element of the parsed contents.xml.in template; changed in place.

  • PartitionRoot (xml.etree.ElementTree.Element) -- Root element of the parsed partitions.xml.

  • BuildId (str) -- Text written to each build_id element; may be empty.

Example: UpdateMetaData(ParseXML("contents.xml.in"), ParseXML("partitions.xml"), "")
