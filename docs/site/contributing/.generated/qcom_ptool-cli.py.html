qcom_ptool.cli._build_parser() → argparse.ArgumentParser¶

Build the top-level qcom-ptool argument parser.

Returns:

Parser that accepts -V/--version and one subcommand name.

Example: _build_parser().parse_known_args(["ptool", "-x", "partitions.xml"]) separates ptool from its remaining arguments.

qcom_ptool.cli.main() → None¶

Run the subcommand named on the command line.

The remaining arguments are passed to the subcommand module through sys.argv. An unknown subcommand makes argparse exit with status 2.

Example: qcom-ptool gen_partition -i partitions.conf -o partitions.xml calls this function.
