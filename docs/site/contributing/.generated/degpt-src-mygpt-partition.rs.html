type Error¶

fn try_from(buf: &[u8]) -> Result<Self, Self::Error>¶

Parse a 128-byte GPT partition entry.

Returns an error when a GUID cannot be read or the name is not valid UTF-16. Panics when buf is shorter than 128 bytes.

Example: Partition::try_from(&bytes[0x2000..0x2080])? reads the first entry of an image with 4096-byte sectors.
