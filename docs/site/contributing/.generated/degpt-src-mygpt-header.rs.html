type Error¶

fn try_from(buf: &[u8]) -> Result<Self, Self::Error>¶

Parse the first 92 bytes of buf as a GPT header.

Returns an error when the signature is not UTF-8 or the disk GUID cannot be read. Panics when buf is shorter than 92 bytes.

Example: Header::try_from(&bytes[0x1000..0x2000])? reads the primary header of an image with 4096-byte sectors.
