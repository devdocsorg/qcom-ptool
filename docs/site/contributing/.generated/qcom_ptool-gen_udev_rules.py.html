qcom_ptool/gen_udev_rules.py¶

Source

Generate udev rules for Qualcomm raw partitions.

qcom_ptool.gen_udev_rules.load_filesystem_names() → set[str]¶

Load names of partitions that may contain filesystems.

Returns:

Partition names from filesystem-partition-names.list.

Raises:

ValueError -- If a name is invalid or duplicated, or the list is empty.

Example: "rootfs" in load_filesystem_names() returns True.

qcom_ptool.gen_udev_rules.load_partition_names(inputs: list[pathlib.Path]) → set[str]¶

Load and merge partition names from all supplied layouts.

Parameters:

inputs -- Partition layout files to load.

Returns:

Every partition name except empty names and last_parti.

Raises:

ValueError -- If a layout contains a name unsafe for a udev rule.

Example: load_partition_names([Path("platforms/qcs6490-rb3gen2/ufs/partitions.conf")])

qcom_ptool.gen_udev_rules.load_raw_partition_names(inputs: list[pathlib.Path]) → list[str]¶

Return known raw partition names from the supplied layouts.

Parameters:

inputs -- Partition layout files to load.

Returns:

Sorted names that are not listed as filesystem partitions.

Example: "xbl_a" in load_raw_partition_names(layouts) returns True for a layout with an xbl_a partition.

qcom_ptool.gen_udev_rules.discover_inputs(inputs: list[pathlib.Path] | None) → list[pathlib.Path]¶

Use explicit layouts or discover all layouts in the current repo.

Parameters:

inputs -- Explicit layout paths, or None/empty to search platforms/*/*/partitions.conf below the current directory.

Returns:

The layout paths to scan.

Raises:

ValueError -- If no layout is supplied or found.

Example: discover_inputs(None) run from the repository root returns every partitions.conf under platforms/.

qcom_ptool.gen_udev_rules.render_rules(names: list[str]) → str¶

Render the udev rules template for the supplied partition names.

Parameters:

names -- Raw partition names to match.

Returns:

The rules file text with one ENV{PARTNAME} rule per name.

Raises:

ValueError -- If the template does not contain exactly one placeholder.

Example: render_rules(["xbl_a"]) contains ENV{PARTNAME}=="xbl_a".

qcom_ptool.gen_udev_rules.generate_rules(inputs: list[pathlib.Path] | None = None) → str¶

Render rules for raw partitions in all supplied layouts.

Parameters:

inputs -- Explicit layout paths, or None to discover them.

Returns:

The rendered rules file text.

Raises:

ValueError -- If no layout is found or a name or template is invalid.

Example: generate_rules() run from the repository root renders rules for all layouts.

qcom_ptool.gen_udev_rules.parse_args(argv: list[str] | None = None) → argparse.Namespace¶

Parse the gen_udev_rules command-line options.

Parameters:

argv -- Arguments without the program name; None reads sys.argv.

Returns:

Namespace with input (list of paths or None) and output.

Raises:

SystemExit -- With status 2 when -o/--output is missing.

Example: parse_args(["-o", "55-qcom-raw-partitions-noblkid.rules"]).input returns None.

qcom_ptool.gen_udev_rules.main(argv: list[str] | None = None) → int¶

Write the udev rules file for raw Qualcomm partitions.

Parameters:

argv -- Arguments without the program name; None reads sys.argv.

Returns:

0 on success, or 2 when a layout, name list, template or output fails.

Example: main(["-o", "55-qcom-raw-partitions-noblkid.rules"]) prints generated: 55-qcom-raw-partitions-noblkid.rules.
