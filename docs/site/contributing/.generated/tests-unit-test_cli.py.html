Tests for the qcom-ptool CLI dispatcher.

unit.test_cli.subprocess_env()¶

Return the environment with the repository root on PYTHONPATH.

Returns:

A copy of os.environ for subprocesses.

Return type:

dict[str, str]

Example: subprocess.run(cmd, env=subprocess_env())

unit.test_cli.run_cli(*args)¶

Run python -m qcom_ptool.cli with arguments and capture its output.

Parameters:

args (str) -- Command-line arguments.

Returns:

The completed process with text output.

Return type:

subprocess.CompletedProcess[str]

Example: run_cli("--version").returncode returns 0.
