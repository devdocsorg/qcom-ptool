tests/unit/test_board.py¶

Source

Unit tests for the multi-storage board resolver (qcom_ptool/board.py).

These pin the composition contract: board-level extends, storage-level includes (with transitivity), variant overlays, deep-merge by stable identifier, the deterministic ordering rule, cycle detection, and the reduction to a byte-parity LoadedSpec.
