qcom_ptool.utils.EnsureDirectoryExists(filename)¶

Create the parent directory of a file path when it does not exist.

Parameters:

filename (str) -- Path whose directory component must exist.

Raises:

OSError -- If the directory cannot be created.

Example: EnsureDirectoryExists("out/rawprogram0.xml") creates out/.

qcom_ptool.utils.PrintBigWarning(sz, log_func=print)¶

Print a large WARNING banner followed by an optional message.

Parameters:

  • sz (str) -- Message printed after the banner; an empty string prints only the banner.

  • log_func (collections.abc.Callable) -- Function that receives each output line.

Example: PrintBigWarning("SECTOR_SIZE_IN_BYTES changed")

qcom_ptool.utils.PrintBigError(sz, log_func=print)¶

Print a large ERROR banner and exit when a message is supplied.

Parameters:

  • sz (str) -- Error message; a non-empty message ends the program with status 1.

  • log_func (collections.abc.Callable) -- Function that receives each output line.

Raises:

SystemExit -- With status 1 when sz is not empty.

Example: PrintBigError("ERROR: Could not find file") exits with status 1.

qcom_ptool.utils.reflect(data, nBits)¶

Reverse the order of the lowest nBits bits of an integer.

Parameters:

  • data (int) -- Value whose bits are reflected.

  • nBits (int) -- Number of low-order bits to reflect.

Returns:

The reflected value.

Return type:

int

Example: reflect(0x01, 8) returns 0x80.

qcom_ptool.utils.CalcCRC32(array, Len)¶

Calculate the IEEE CRC-32 used in GPT headers and partition arrays.

Parameters:

  • array (bytes | list[int]) -- Bytes, or a list of byte values, to checksum.

  • Len (int) -- Number of leading bytes of array to include.

Returns:

The CRC-32 value, matching binascii.crc32().

Return type:

int

Example: CalcCRC32(b"123456789", 9) returns 0xCBF43926.
