qcom_ptool/loaders/yaml.py¶

Source

Loader for the structured YAML partition source (single storage).

A YAML document describes one disk mapping and a partitions list; this module validates it against qcom_ptool/schema/partitions.schema.json and normalises it into the exact same qcom_ptool.spec.LoadedSpec the .conf loader produces, so both formats emit byte-identical XML.

Normalisation mirrors loaders/conf.py field for field: the disk dict is built by copying DISK_PARAMS_DEFAULTS and each partition by copying PARTITION_ENTRY_DEFAULTS, so key order (and therefore XML attribute order) matches the legacy loader. partition_size_in_kb and the attribute-bit decoding are reused / replicated identically.

class qcom_ptool.loaders.yaml.YamlParseError¶

qcom_ptool.loaders.yaml._bool_str(value: Any) → str¶

Render a YAML scalar as the lowercase "true"/"false" the .conf loader stores. str(True) would yield "True", which the emitter would then write verbatim and break parity, so booleans are normalised explicitly.

Parameters:

value -- YAML scalar value.

Returns:

"true"/"false" for booleans, otherwise str(value).

Example: _bool_str(True) returns "true".

qcom_ptool.loaders.yaml.load_schema() → dict[str, Any]¶

Return the packaged partition JSON Schema as a dict.

Returns:

The parsed partitions.schema.json.

Example: load_schema()["required"] returns ["disk", "partitions"].

qcom_ptool.loaders.yaml._disk_from_node(node: collections.abc.Mapping[str, Any]) → qcom_ptool.spec.DiskParams¶

Normalise the disk mapping into the canonical disk dict.

Starts from DISK_PARAMS_DEFAULTS and overrides only the keys present, exactly like conf.disk_options, so unset fields keep their defaults and the key order is identical.

Parameters:

node -- disk mapping, or a resolved board storage.

Returns:

A copy of DISK_PARAMS_DEFAULTS updated from the mapping.

Raises:

KeyError -- If type or size is missing.

Example: _disk_from_node({"type": "ufs", "size": 1024})["type"] returns "ufs".

qcom_ptool.loaders.yaml._partition_from_node(node: collections.abc.Mapping[str, Any], image_map: collections.abc.Mapping[str, str]) → tuple[str, qcom_ptool.spec.PartitionEntry]¶

Normalise one partition mapping into (phys_part, entry).

Mirrors conf.partition_options: same defaults, same attribute-bit decoding, and the image-map override applied last so it always wins.

Parameters:

  • node -- One partition mapping.

  • image_map -- Partition name to image filename overrides.

Returns:

The LUN or physical partition as a string, and the partition entry.

Raises:

KeyError -- If name, size or type-guid is missing.

Example: _partition_from_node({"name": "efi", "size": "4KB", "type-guid": guid}, {})[0] returns "0".

qcom_ptool.loaders.yaml.load(path: str, image_map: collections.abc.Mapping[str, str] | None = None) → qcom_ptool.spec.LoadedSpec¶

Public entry point: read path and return a normalised LoadedSpec.

Parameters:

  • path -- YAML file to read.

  • image_map -- Partition name to image filename overrides.

Returns:

The normalised disk settings and partitions.

Raises:

YamlParseError -- If the document is not a mapping or fails schema validation.

Example: load("tests/unit/data/glymur-crd-nvme.yaml")["disk"]["type"] returns "nvme".
