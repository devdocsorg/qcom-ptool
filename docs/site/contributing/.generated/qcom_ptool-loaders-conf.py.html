qcom_ptool/loaders/conf.py¶

Source

Loader for the legacy --disk / --partition line-format files under platforms/.

A .conf file is an unstructured stream of comment lines, blank lines, exactly one --disk line, and any number of --partition lines. Each significant line is itself a getopt-style option list. This module parses both layers and returns a qcom_ptool.spec.LoadedSpec.

The parsing helpers are kept individually addressable so the unit tests under tests/unit/ can characterise each layer in isolation.

qcom_ptool.loaders.conf.partition_size_in_kb(size: str) → int¶

Convert a size string ("1024", "1KB", "2MB", "1GB") to KB.

Bare integers are interpreted as bytes and divided by 1024. Strings with a K/M/G suffix (any case, with optional 'B') return the kilobyte equivalent. Anything else raises ValueError; callers may catch and reformat.

Parameters:

size -- Size string.

Returns:

Size in kilobytes.

Raises:

ValueError -- If the string has letters but no K, M or G suffix.

Example: partition_size_in_kb("2MB") returns 2048.

Translate parsed --disk options into the canonical disk dict.

Parameters:

argv -- (option, value) pairs from getopt.gnu_getopt().

Returns:

A copy of DISK_PARAMS_DEFAULTS updated from the options.

Example: disk_options([("--type", "ufs")])["type"] returns "ufs".

Normalise a boolean option value to "true" or "false".

"true" or "false".

qcom_ptool.loaders.conf.partition_options(argv: list[tuple[str, str]], image_map: collections.abc.Mapping[str, str] | None = None) → tuple[str, qcom_ptool.spec.PartitionEntry]¶

Translate parsed --partition options into (phys_part, entry).

image_map (if provided) overrides the entry's filename when the partition name matches a key. The override is applied after all options have been processed, so it always wins over an explicit --filename.

Parameters:

  • argv -- (option, value) pairs from getopt.gnu_getopt().

  • image_map -- Partition name to image filename overrides.

Returns:

The LUN or physical partition as a string, and the partition entry.

Raises:

ValueError -- If a size, attribute, priority or retry value is malformed.

Example: partition_options([("--lun", "1"), ("--name", "xbl_a")])[0] returns "1".

qcom_ptool.loaders.conf.parse_disk_line(line: str) → qcom_ptool.spec.DiskParams | None¶

Parse a single --disk ... line; return None if the line isn't one.

Parameters:

line -- One stripped line from a .conf file.

Returns:

The disk settings, or None when the line is not a --disk line.

Raises:

getopt.GetoptError -- If the line contains an unknown option.

Example: parse_disk_line("--disk --type=emmc --size=1024")["type"] returns "emmc".

qcom_ptool.loaders.conf.parse_partition_lines(lines: list[str], image_map: collections.abc.Mapping[str, str] | None = None) → qcom_ptool.spec.PartitionsByLun¶

Parse a list of --partition ... lines, grouped by LUN/phys-part.

Parameters:

  • lines -- Stripped lines; lines that are not --partition lines are skipped.

  • image_map -- Partition name to image filename overrides.

Returns:

Partition entries grouped by LUN or physical partition.

Raises:

getopt.GetoptError -- If a line contains an unknown option.

Example: parse_partition_lines(["--partition --name=efi --size=4KB"])["0"][0]["label"] returns "efi".

qcom_ptool.loaders.conf.read_conf(path: str) → tuple[str, list[str]]¶

Read path and return (disk_line, [partition_lines]).

Comments (#-prefixed) and blank lines are skipped. Multiple --disk lines are an error. Lines that aren't --disk or --partition are printed as "Ignoring ..." for parity with the original behaviour.

Parameters:

path -- .conf file to read.

Returns:

The --disk line and the --partition lines in file order.

Raises:

ConfParseError -- If the file has no --disk line or more than one.

Example: read_conf("platforms/qcs6490-rb3gen2/ufs/partitions.conf")[0] returns the --disk line.

qcom_ptool.loaders.conf.load(path: str, image_map: collections.abc.Mapping[str, str] | None = None) → qcom_ptool.spec.LoadedSpec¶

Public entry point: read path and return a normalised LoadedSpec.

Parameters:

  • path -- .conf file to read.

  • image_map -- Partition name to image filename overrides.

Returns:

The normalised disk settings and partitions.

Raises:

ConfParseError -- If the file has no --disk line or more than one.

Example: load("platforms/apq8016-sbc/emmc/partitions.conf")["disk"]["type"] returns "emmc".
