Create an empty log_msp.txt in the current directory.

SystemExit -- When the log file cannot be created.

Example: reset_device_log()

qcom_ptool.msp.device_log(message, display=1)¶

Append a time-stamped message to log_msp.txt and optionally print it.

Write failures print an error and are otherwise ignored.

Parameters:

  • message (str) -- Text to log.

  • display (int) -- 1 to also print the message.

Example: device_log("Writing rawprogram0.xml", display=0)

Read whole sectors from an open file or device.

Parameters:

  • opfile (BinaryIO) -- Open binary file or device.

  • NumSectors (int) -- Number of SECTOR_SIZE sectors to read.

Returns:

The bytes read.

Return type:

bytes

Raises:

SystemExit -- With status 1 when the read fails.

Example: ReadSectors(fp, 1) returns the first 512 bytes of fp.

Run a shell command and return its output.

Parameters:

  • command (str) -- Command line to run.

  • capture_output (bool) -- True to capture stdout and stderr; False runs it with os.system().

bytes | None

SystemExit -- With status 1 when the command cannot be started.

Example: external_call("sync")

qcom_ptool.msp.HandleNUM_DISK_SECTORS(field)¶

Replace NUM_DISK_SECTORS expressions with sector numbers.

When the disk size is not known yet, the value is placed beyond the largest supported disk so entries sort after absolute sectors.

Parameters:

field (str | int) -- Value such as "NUM_DISK_SECTORS-33.", or a number.

Returns:

The sector number, or field unchanged when it is already a number.

Return type:

int | str

Example: HandleNUM_DISK_SECTORS(34) returns 34.

Example: PerformRead() runs when the XML contains read elements.

qcom_ptool.msp.PerformWrite()¶

Write each program entry's file to the destination.

Returns:

1 when an image larger than its partition was truncated, otherwise 0.

Return type:

int

Raises:

SystemExit -- When an image cannot be opened or the destination cannot be written.

Example: PerformWrite() writes the images listed in rawprogram0.xml.

qcom_ptool.msp.GetPartitions()¶

Record the disks the operating system reports in AvailablePartitions.

On Linux this reads /proc/partitions; on Windows it queries the physical drives.

Example: GetPartitions()

qcom_ptool.msp.PerformPatching()¶

Apply each patch entry to the destination or to a file.

Patches to the disk require confirmation unless prompts are disabled.

Raises:

SystemExit -- When a patch cannot be applied.

Example: PerformPatching() updates the GPT CRCs listed in patch0.xml.
