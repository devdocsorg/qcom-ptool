qcom-ptool documentation¶

qcom-ptool turns the partition layouts in this repository into GPT images and the XML files that Qualcomm flashing tools read.

  • Generate partition files for a board walks through one layout.

  • The configuration reference describes the layout formats and build settings.

  • Development setup installs the tools and runs the checks.

  • The contribution guide explains how to submit changes.

  • The function reference is generated from the source comments.

Folders¶

  • user/ — Holds the tutorial and the configuration reference.

  • contributing/ — Holds the contribution guide, development setup, and function reference.

  • .templates/ — Supplies the generated site's entry-point redirect.

Files¶

  • Makefile — Provides the shared local and CI setup, build, and check commands.

  • README.md — Introduces the guides and supplies the site's homepage.

  • conf.py — Configures Markdown rendering, the Python and Rust function reference, local navigation, and search.

  • requirements.txt — Pins the documentation packages.

  • requirements.lock — Locks direct and transitive documentation dependencies for reproducible builds.
