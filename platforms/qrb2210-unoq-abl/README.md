# qrb2210-unoq-abl

Partition layouts for the `qrb2210-unoq-abl` board, one folder per storage device. These are the pre-edk2 tables for the ABL-based boot firmware.

## Folders

- [emmc-16GB/](emmc-16GB/README.md) — Holds the 16 GB eMMC layout.
- [emmc-16GB-arduino/](emmc-16GB-arduino/README.md) — Holds the 16 GB eMMC layout with a `userdata` partition.
