# glymur-crd SPI-NOR storage

Contents template for the SPI-NOR storage of the `glymur-crd` board, whose partitions come from [boards/glymur-crd.yaml](../../boards/glymur-crd.yaml). `make` writes the generated files here, and Git ignores them. The [configuration reference](../../../docs/source/user/CONFIGURATION.md) describes the formats.

## Files

- [contents.xml.in](contents.xml.in) — Is the template that `gen_contents` turns into `contents.xml`.
- [README.md](README.md) — Describes this folder and indexes its contents.
