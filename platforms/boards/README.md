# Board files

YAML board files that describe every storage of a board. `make` builds each one into `platforms/<board>/<storage-id>/`; the [configuration reference](../../docs/source/user/CONFIGURATION.md#board-files-yaml) describes the keys.

## Files

- [glymur-crd.yaml](glymur-crd.yaml) — Defines the NVMe and SPI-NOR storages of the `glymur-crd` board.
- [README.md](README.md) — Describes this folder and indexes its contents.
