# qrb5165-rb5 UFS storage

Layout for the UFS storage of the `qrb5165-rb5` board. `make` writes the generated files next to it, and Git ignores them. The [configuration reference](../../../docs/source/user/CONFIGURATION.md) describes the formats.

## Files

- [partitions.conf](partitions.conf) — Defines the disk and its partitions in the `.conf` layout format.
- [README.md](README.md) — Describes this folder and indexes its contents.
