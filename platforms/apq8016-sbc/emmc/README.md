# apq8016-sbc eMMC storage

Layout for the eMMC storage of the `apq8016-sbc` board. `make` writes the generated files next to it, and Git ignores them. The [configuration reference](../../../docs/source/user/CONFIGURATION.md) describes the formats.

## Files

- [partitions.conf](partitions.conf) — Defines the disk and its partitions in the `.conf` layout format.
- [README.md](README.md) — Describes this folder and indexes its contents.
