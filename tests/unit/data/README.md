# Test fixtures

The same NVMe layout in both source formats, kept here so the parity tests do not
depend on the layouts under `platforms/`.

## Files

- [README.md](README.md) — Describes this folder and indexes its contents.
- [glymur-crd-nvme.conf](glymur-crd-nvme.conf) — Gives the layout in the `.conf` line format.
- [glymur-crd-nvme.yaml](glymur-crd-nvme.yaml) — Gives the same layout as a single-storage YAML file.
