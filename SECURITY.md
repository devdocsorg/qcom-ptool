# Security policy

Report suspected vulnerabilities in qcom-ptool privately. Do not use public issues,
pull requests, or discussions for them.

Email Qualcomm's [Product Security team](mailto:product-security@qualcomm.com) or use
Qualcomm's [Report a Bug](https://www.qualcomm.com/company/product-security/report-a-bug)
page. Name this repository, the affected file or commit, the likely impact, and the
steps to reproduce. Qualcomm's
[open source security policy](https://github.com/qualcomm/.github/blob/main/SECURITY.md)
describes how reports are handled.
