# Security policy

## Report privately

Report a vulnerability that is not yet public through
[GitHub's private vulnerability reporting](https://github.com/qualcomm-linux/qcom-ptool/security/advisories/new)
for this repository, by email to the
[Qualcomm Product Security team](mailto:product-security@qualcomm.com), or through
the [Report a Bug](https://www.qualcomm.com/company/product-security/report-a-bug)
page. Include the affected file or commit, likely impact, safe reproduction steps,
and a way to contact you. Keep vulnerability details out of public issues and pull
requests.

Report an issue that is already public, such as one with a released CVE number, as
a [GitHub issue](https://github.com/qualcomm-linux/qcom-ptool/issues/new/choose).

## Supported versions

The repository does not state which versions receive security fixes. `main` is its
only branch; see [BRANCHES.md](BRANCHES.md).
